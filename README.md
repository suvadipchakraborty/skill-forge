# The Shelf (v2)

A mobile-first, app-store-style page listing all of Suva's small apps. Static
`public/` directory served by a thin Cloudflare Worker via the assets binding.

Live at: https://apps.suvadipchakraborty.workers.dev/

## What's in v2

- **Tabs by category**: All, Around you, Health & safety, Learn, Through time, World & culture, Games. Swipe left/right on the list to change tab.
- **Search** by name or topic (keywords live in `build.py`).
- **My shelf**: pin apps with the star (or press and hold), plus recently opened. Stored on the device only.
- **Settings**: theme (Auto/Light/Dark), icon style (Vivid/Soft/Mono), text size, layout (Tiles / List / Icons), order (By category / A to Z), reduce motion, install, check for updates, share, reset.
- **Pre-filled emails**: feedback, report a broken app, suggest an app. Subject and prompts are filled in, plus device/app details at the bottom.
- **Today's pick**: one app highlighted per day.
- Every app has its own icon; colour encodes category.
- Fonts (Bricolage Grotesque, Figtree, both OFL) are self-hosted in `public/fonts/`, so they also work offline.

## Structure

```
build.py            all app data, categories and icons; generates public/index.html
template.html       page shell used by build.py (not deployed)
public/
  index.html        GENERATED by build.py. Do not edit by hand.
  css/styles.css
  js/app.js
  sw.js             network-first service worker
  manifest.webmanifest
  fonts/            self-hosted woff2 + licences
  assets/           og-image + app icons (regenerate with gen_assets.py)
src/worker.js       hands every request to the ASSETS binding
wrangler.toml
```

## Adding a new app

1. Open `build.py`.
2. Add one tuple to `APPS` (id, name, category id, short tagline, long description, url, search keywords).
3. Add a 24x24 stroke icon for the same id to `GLYPHS`.
4. Optional: add the id to `NEW` to show a "New" badge (remove it later).
5. Run `python3 build.py`. It rewrites `public/index.html`, the JSON-LD list and every app count.
6. Bump `SHELL_CACHE` in `public/sw.js` (`shelf-shell-v11` to `v12`).
7. Commit and push. Cloudflare deploys it.

New category: add it to `CATEGORIES` and add a matching
`[data-cat="x"] { --h: ...; --fb1: ...; --fb2: ...; }` rule in `styles.css`.

## Don't break installed home-screen copies

Installed copies track the live site, so shipping updates needs no reinstall as long as these stay put:
`start_url` and `scope` (`/`), `id` (`/`), the manifest `name`, the icon paths in
`/assets/`, and the service worker URL (`/sw.js`). The service worker is
**network-first** on purpose (a cache-first shell once hid bug fixes from
returning visitors). Settings, pins and recents live in `localStorage`
(`shelf-prefs`, `shelf-pins`, `shelf-recent`); the old `shelf-theme` value is
migrated automatically.

## Deploy

Push to GitHub, connect the repo in Cloudflare (Workers & Pages), root directory
= repo root, no build command (run `build.py` locally and commit its output).
If the domain changes, update the absolute URLs in `build.py` (`SITE`),
`public/sitemap.xml` and `public/robots.txt`.
